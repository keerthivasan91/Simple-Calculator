# Simple Mobile Calculator

A clean, responsive calculator with basic arithmetic operations that looks like a mobile calculator.

## Features

- Basic operations: addition, subtraction, multiplication, division
- Clear (AC) and delete (DEL) functions
- Two-line display showing current and previous operations
- Decimal point support
- Responsive design that works on mobile and desktop

## Files

- `index2.html` - Main HTML structure
- `styles3.css` - Styling for the calculator
- `script3.js` - Calculator functionality
